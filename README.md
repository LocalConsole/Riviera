# Riviera Ice — демо-сайт катка

Один файл `index.html`, без сборки и зависимостей.

## Деплой на Render
1. Залей папку в репозиторий GitHub.
2. Render → New → Static Site → выбери репозиторий.
3. Build Command: пусто. Publish Directory: `.`
   (или New → Blueprint — подхватит `render.yaml`).

## Локально
Просто открой `index.html` в браузере.
